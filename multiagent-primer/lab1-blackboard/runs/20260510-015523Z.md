### [agent-1 · 2026-05-09T21:15:32Z] Setup: 25 agents in Smallville with memory-planning-reflection architecture
**Section:** Setup
**Finding:** The experiment populated a sandbox village ("Smallville") with 25 autonomous agents running on GPT-3.5. Each agent had three core architectural components: observation (perceiving the environment), planning (deciding actions for the day), and reflection (synthesizing memories to improve future behavior). The environment contained functional spaces like a cafe, bar, park, school, and houses with detailed sub-areas (e.g., kitchen with stove).
**Source:** https://arxiv.org/pdf/2304.03442


### [agent-1 · 2026-05-09T21:15:47Z] Emergent behaviors: Valentine's party planning and political discussion
**Section:** Emergent behaviours
**Finding:** When researchers seeded the world with a single user-specified event (one agent wanting to throw a Valentine's Day party), agents autonomously spread invitations over two days, made new acquaintances, asked each other on dates to attend, and coordinated arrival times—all unscripted. Additionally, when one agent announced he was running for mayor, others remembered the information and discussed it naturally in subsequent conversations at the grocery store and elsewhere.
**Source:** https://arxiv.org/pdf/2304.03442


### agent-2 · 2026-05-10T01:51:00Z · Smallville: 25 agents with memory-planning-reflection stack
**Section:** Setup
**Finding:** The experiment deployed 25 AI agents in Smallville, a 2D sandbox environment with houses, businesses, a university, and park. Each agent was initialized with a single paragraph of natural language description as seed memory. The core architecture has three components: a memory stream (records all perceptions), retrieval (fetches relevant memories), planning (generates multi-step goals), and reflection (synthesizes abstract insights). Agents run on ChatGPT (GPT-3.5).
**Source:** https://arxiv.org/abs/2304.03442

### [agent-1 · 2026-05-09T21:15:58Z] Limitations: Memory hallucinations and robustness vulnerabilities
**Section:** Limitations
**Finding:** Agents exhibited specific failures in memory handling: agents sometimes failed to retrieve key memories and embellished others with false details (e.g., Yuriko incorrectly described neighbor Adam Smith as the economist-author of The Wealth of Nations). The system also showed robustness vulnerabilities to prompt injection attacks and memory manipulation, plus concerning degradation in believability as simulations lengthened. Additionally, LLM instruction tuning caused agents to speak unnaturally formally or politely to each other.
**Source:** https://arxiv.org/pdf/2304.03442
